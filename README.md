### 🌟 Featured Work

**🏨 Rentify — Hotel Booking Platform**
Responsive React frontend with a FastAPI backend for listings, reservations, and cancellations; TanStack Query for data fetching, TypeScript throughout.
`React` `FastAPI` `TanStack Query` `Zustand`

**🎸 ChordLyrics — Full-Stack Chord & Lyrics Platform**
Next.js 14 + NestJS platform with song CRUD, admin approval workflows, and role-based access. Layered state architecture (RTK Query + Jotai + Zustand), Gemini AI chord generation with voice input, and a separate admin panel with runtime-configurable AI usage limits.
`Next.js 14` `NestJS` `RTK Query` `Jotai` `Gemini AI` `PostgreSQL`

**🍔 Speedy Chow — Food Delivery Platform**
Cross-platform Flutter app with offline-first cart (Riverpod + Secure Storage), Razorpay payments, FCM push notifications, and biometric auth. Paired with a Next.js 14 admin panel for product, order, and revenue management.
`Flutter` `NestJS` `Next.js 14` `Riverpod` `Razorpay` `PostgreSQL`

**⚡ Red CLI — Full-Stack Scaffolding Tool**
A CLI that spins up production-grade Next.js, React Native, React, and Node.js projects pre-configured with TypeScript, auth, Swagger docs, React Query, and payment integrations.
`Next.js` `React Native` `Node.js`
